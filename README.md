# dsh-task-board — DSH Web GUI 任务看板插件

在侧边栏底部「设置」旁（官方 `sidebar.footer.action` 槽）增加**任务看板**入口：多列看板管理任务，任务以 DSH 自身的会话机制
**真实执行**，状态实时回写卡片。不修改 DSH 源码，卸载即恢复原状；任务数据持久化在 DSH
host 端，**桌面与手机（任何设备、任何地址）打开同一部署看到的都是同一块板，改动实时同步**；
窄屏自动进入紧凑布局，交互与桌面完全对齐（同一套悬停操作与拖拽手势）。

## 核心能力

- **多端实时同步（host 唯一真相）**：看板数据（任务、巡航、预设）由 DSH host 端持久化
  （`~/.dsh/storages/dsh_task_board.json`，人可读、可备份），浏览器只是乐观副本：
  电脑建卡 → 手机秒级可见，手机操作 → 电脑同步更新；同浏览器多标签也共享同一份真相。
  两端并发编辑按记录合并，**同步不依赖设备时钟**——你最新做出的操作一定生效（手机时钟
  偏差几分钟也不丢不乱，包括会话拖拽排序、隐藏/恢复会话、隐藏托盘删除、自动化规则开关
  这类容易漏同步的编辑）；弱网/断线时看板照常可用
  （本地镜像先渲染），恢复后自动追平。首次升级自动迁移：各设备旧的 localStorage 数据
  按记录并入 host 初始数据（电脑的任务 + 手机上新建的任务都会出现），绝不丢。
- **原生归档即时同步**：在原生工作区里归档一个已绑定会话，任务卡片上的那一行**两端同帧消失**
  （取消归档又带完整历史回来）——行派生自原生真相，不经台账，零延迟。
- **原生对话实时上板**：在原生会话里直接发言，对应任务卡片**立刻**进入「进行中」并带上
  你那句话（事件级感知，秒回的短对话也不会漏）；跑完落「待审核」，两端一致。
- **引擎租约（多端绝不双跑，且跟着你走）**：定时/巡航/接续/自动化发射等时间驱动行为同一时刻只由
  一个打开的 GUI 端执行（host 租约仲裁，秒级接管）；多端同开不会重复触发、不会重复
  消耗额度。**引擎席位跟着可见性走**——你正在看的那台设备就是引擎，手机退后台、电脑上前台时
  电脑立刻接管并补上期间漏掉的状态（不会出现在手机点了没反应、要等刷新的情况）。

- **五列看板**：待规划 / 待办 / 进行中 / 待审核 / 已完成。卡片只显示状态摘要（标题、描述、
  来源、状态与自动化徽章、更新时间），执行窗口与评论时间线在详情页。
- **真实执行**：点「执行」即开跑；执行会话出现在原生会话列表，可点进去看完整对话。
  执行 Prompt 以 `/` 开头时按原生命令执行（如 `/plan ...` 真实进入计划模式）。
- **执行 Prompt 为空时执行全阻断**：手动点执行、快速执行、重新执行、定时/接续自动化、
  自动巡航、会话规则（把**任务执行 Prompt**作为内容的规则）——空 Prompt 一律拒绝
  （界面会提示原因；「完成后接续」不会假死：空 Prompt 时武装直接被拒并说明）。
  **评论与插话永不灰**：留言是人的话，只有会话不存在时才禁用。需求完善流程不受影响
  （它正是用来产出 Prompt 的）。
- **评论即驱动**：每条会话行打开对应面板，左侧实时对话（Markdown 预览），右侧计量、
  运行配置、评论线程与发送区。留言默认**排队**（等**本条会话**空出来按序注入、可取消；
  别的会话在跑绝不拖累它，见下条「并行按会话算」），或切**插话**
  立即送达（官方 `steer` 模式——真插话：任务立即进入「进行中」、完成后落「待审核」并触发完成约定，与会话规则/外源轮共用同一运行态推导）；`/` 斜杠命令走原生命令注册表；**`@` 走官方引用机制**（与主界面输入框
  完全一致）：@ 文件/文件夹（`@"带空格路径"` 引号文法、目录下钻），@ 会话（插入
  官方 `@[会话](dsh-session:…)` 引用，发送后 host 自动把被引用会话的快照注入上下文
  ——所有输入框共用同一套；会话域官方候选不可用时（如目标会话由子代理路由托管，
   官方与主界面同样静默）会自动以板内会话目录列出（插入的仍是官方 `@[label](dsh-session:…)` 引用，host 照常解析快照上下文）；
   文件域失败时与主界面一致地静默（原因见浏览器控制台日志）；只有两域都成功且真无候选才显示「没有匹配的文件或会话」；
   选中后菜单即关、只有选目录才自动续开下一层）；可发图片与任意文件（官方消息通道：手机相册/拍照、桌面点选/拖到输入框任意处/Ctrl+V 粘贴，同一套；图片在浏览器内先压缩再发送，**其他文件按原字节上传**，无法识别或超标的文件明确说原因、绝不静默丢弃；发出后评论区与对话里都能看到缩略图、点开看原图；失败给明确原因且内容不丢）。
   图片与文件不止评论区：新建/编辑任务的「执行 Prompt」可附参考（图片压缩后随任务持久、每次执行连同文字发出），需求完善的回答框同样可附。
- **@ 引用能力边界（官方身份政策，如实说明）**：官方把「子代理路由会话」（会话起源为 subagent、或挂在活跃父代理下的会话）上的通用 RPC 一律拦截（`agent-busy`，官方语义：子代理会话请走子代理投递通道）——主界面官方 composer 在此类会话里 @ 同样不可用，且官方无版本修复（该政策自 rc.8 起即目前形态）。因此 @ 请以普通会话（`session-` 前缀）为目标，即可与官方完全一致地引用文件与会话；在子代理会话中，板内输入框以「板内会话目录 + 官方引用文本」提供 @ 会话（宿主照常解析），文件引用不可用（官方政策）。
- **agent 挂起时评论区可见**：计划确认/提问卡实时出现（与原生会话同一来源），点「去会话回答」
  跳到原生会话作答（普通留言不解决挂起问题）；同区的 to-do / goal / 子代理与原生 TodoPanel 同源显示，
  且**有未完成的才显示**（全部完成即收起；进行中的 goal / 子代理才出现）。
   会话的 goal 可在板内直接**暂停 / 恢复 / 行内改目标 / 清除**（与原生目标栏同一套语义），
   用量行显示整轮累计输入输出与缓存，另有一行轮数/步数与模型工具耗时。
- **状态光效**：卡片与会话行按状态呼吸（进行中 / 等待回应 / 完善中；已结束未读也呼吸），
  打开详情或复盘即清除；已读已结束与空闲保持安静。
- **需求完善**：待规划任务让 AI 调研你的需求、逐条提问，产出可执行 Prompt（确认后才应用）。标题、描述、Prompt 全空时点不了（先写点需求）；完善中卡片留在待规划、只显示"完善中"，不会跳成进行中。
- **自动化（一套系统，两处表面）**：任务详情与看板「自动化」总览是**同一个完整编辑器**
  （分「任务自动化」「会话规则」两个分区，总览卡片 = 一行实时摘要 + 展开编辑，无重复
  开关）。任务级 = 定时 cron / **完成后接续**（**武装即开跑、完成后自动一直接续下一轮**，
  无限或至次数上限；含跳过本次、停止接续；手动移动卡片不会误杀它）；
  会话级 = 给某个会话发指令：内容二选一（自定义指令 / **任务执行 Prompt**——把任务的
  执行 Prompt 定时或每次完成时注入单一会话，改 Prompt 即时生效），触发方式二选一
  （**按时间表** / **每次完成**——完成后继续、一轮接一轮：永续循环，规则的指令轮
  成功结束才续下一轮；关闭/删除/会话消失/内容不可用才停）。**「每次完成」要先完成
  一次才会发第一条**：给会话留言/对话、跑一次任务都算完成；已启动但还没触发时，
  规则行显示「等待任务完成触发」（不是「排队中」——发送方式才是排队/插话）。
  **每条规则都有发送方式
  （排队 = 等自己那条会话空出来，插话 = 完成/到点先发）**：所有规则轮走**自动化车道**——按时
  到点绝不空等板级巡航。**每条规则同时在途至多一轮**。**每会话至多一条规则**：
  同一个会话的自动化是一份定义，改它用编辑，绝不叠多个触发器）。两半互相独立：关任务级
  计划表不影响会话规则。总览只显示**已启动**的自动化。
- **并行按「会话」算，不按「卡片」算**：一张卡片可以同时跑多条互不相干的对话——
  卡片里某条会话正在运行，你在**另一条**会话下用「排队」留的言照样立刻发出，不再白等
  无关对话结束。**板头那个「并行数」就是唯一的闸门**：它是"同时最多跑几个会话"，
  设成 3 就是三条对话齐头并进，设成 1 就退回严格一条一条来（这也是防止一堆定时规则
  在同一瞬间齐发抢额度的阀门）。同一条会话内永远按提交顺序一条条来（一条对话一次只
  接一件事），「排队中 · 第 N 位」数的也是**本条会话**的队伍。卡片的所在列是所有会话
  的汇总：只要还有任何一条在跑就留在「进行中」，最后一条跑完才落「待审核」。
- **自动巡航（板级）**：看板头一键批量执行全部待办任务；全局并发上限（按会话计，见上）；
  可设定时窗口。
  **总开关是主权**：窗口只在到点自动开/关，增删窗口绝不改变当前开关状态——手动开开关关
  永远匹配得上，拔光窗口也稳定。窗口一行一种显示（「22:00 → 次日 02:00」「1月8日 09:00
  起保持开启」「已开启 · 至 9月17日 06:51」；次日只用于结束是开始**紧邻的第二天**，
  间隔多天按真实日期显示）；状态行永远解释「为什么现在是开/关」；
  结束早于开始 = 一晚内跨次日（超过一天会提示具体差了多少天，请检查日期）。
- **会话统一**：执行记录与链接会话合并为按会话去重的一个列表，同一会话同一条评论线程；
  列表可**上下拖拽排序**（两端同步）；展示可隐藏、隐藏托盘可恢复。**任务卡片的会话
  只来自明确来源**——板内执行、你亲手拖入/新建/「添加会话」选入的会话、需求完善会话；
  **在主界面/工作区里新建的会话绝不会自己溜进任务卡片**（绑定整个工作区只作为来源与
  运行关联，不再灌入其成员会话）。唯一例外是把整个工作区文件夹拖进看板建卡的那一瞬间：
   文件夹里当前可见的会话会一次并入（之后新建的永不自动并入）。**删除 = 从任务移除**（清记录），**把该会话再拖回
  即可恢复显示**。任务已完成时留言自动把它移回「待办」并驱动。
  会话区动作行可**「+ 新建会话」**：按运行配置直接创建一个全新原生会话并加入本任务
  （初始配置 = 任务自身运行配置，可改可套预设），无需回到工作区新建。**标题选填**——
  填写即以此命名并固定（官方 rename，永不被自动改名）；留空则交给宿主自动命名
  （首次对话后自动生成），与新会话在原生侧的表现完全一致。配置/标题某一步没生效时
  会话仍会保留并明确提示。会话行上可**重命名**（行内铅笔图标）：与原生会话列表、
  原生侧标题**同步生效**，且重命名后的标题不再被自动改名。宿主尚未命名的会话
  统一显示「未命名」。
- **拖拽**：卡片拖列移动、同列重排（精确插入条）、**拖到列边缘自动滚动**（一次拖到底/
  到顶）；侧边栏会话/工作区直接拖进看板建卡（拖进详情「会话」区 = 添加来源绑定，绝不
  刷新替代；拖入正在运行的会话立即同步状态；工作区绑定只关联来源，会话列表见「会话
  统一」）。
- **手机/窄屏适配（以看板盒宽度自适应，与侧栏/分屏/窗口大小无关；与桌面同一套代码、同一套行为）**：
  紧凑档五列变为**横向自由滑动列**（约两列同屏、邻列露边暗示可滑）+ **列导航标签五等分一排**
  （五个状态一屏尽收、导航条自身不用滑；窄档用短名「规划/待办/进行/审核/完成」，完整名保留在
  无障碍标签里——绝不出现五个标签都截成「待…」而分不清谁是谁）；点标签直达对应列，反复开合
  侧栏看板**不再跳位**（位置由「当前列」推导，不是残留像素）；板头是**两行确定的成员归属**，
  桌面与手机同一套（不是随机折行）：**导航行 = 返回 · 板名 · 状态（运行/排队/引擎提示，靠左）
  …… 自动巡航 · 新建任务**（右端两个：巡航是常态开关，新建是一次性动作、永远在最右）；
  **工具行 = 筛选任务（靠左，与返回/板名同一条竖线）…… 整理 · 自动化**（靠右成簇）。
  手机上这两行各自再确定性地换行：**第 1 行 返回 · 板名 · 自动巡航 · 新建任务**，
  **第 2 行 状态**（**只有内容才出现**，「排队 0」这类零段不再显示；提示再长也只占自己的行，
  挤不散别的按钮），**第 3 行 筛选任务独占整条白长条**（占位符永远完整可读），
  **第 4 行 整理 · 自动化**（右对齐，与上方右端同一条竖线）——每个控件都保留文字；
  弹窗/详情/复盘全部随
  面板定尺、可滚动、底部按钮永远可达；**评论/会话面板与桌面同一个骨架、同一份 DOM**：
  手机点进去**直接看到的就是对话内容，下面就是留言输入框**（发送框永远钉在面板底边、拇指处，
  不再被任何内容顶出屏幕），「上下文与运行配置」与「评论」是标题下面**两个独立折叠**（默认收起），
  展开任意一个都只在自己那块限高的区域里滚，**既不截断对话与留言框、也绝不互相遮盖**；
  桌面仍是左对话 + 右栏（折叠块 + 钉底发送框）的几何，逐像素未变；配置展开=完整渲染
  （**折叠体内没有内部滚动条——配置裁在"模型"一行还带自己的滑块正是"显示不全"的病**），
  箭头**折叠朝右、展开朝下**统一折叠语言；**排队/插话的说明与"为什么不能发"写在发送框下面**
  （折叠收起时也在——手机没有悬停，必要说明不能只藏在鼠标提示里）；桌面头部一行 = 标题+徽标+会话上下文+刷新+查看会话+叉 严格同一水平线；手机两行 = 第一行 标题+徽标+叉（叉在最右、标题单行省略号、完整名悬停可见），第二行 = **会话上下文（左）+ 刷新/查看会话（右）**——上下文就在"刷新"左边、统一水平面；
  **配置读取三态分明**：读取中显示安静的"读取中"（不再把在途误报成红色"暂不可用"），失败自动
  重试并给行内「重试」按钮，回到前台也会再试；对话读取同理，短暂断线自愈；会话行的**图形、工作区标签、
  状态徽章、时间行全部对齐在同一条左边界**（标题缩进在图形之后），未读点改为**压在图形右上角的小徽标**——
  有没有未读，每一行的几何都相同，标题再也不会被挤成一个字；
  表单行（Cron 表达式、预设管理、详情底部按钮）与区块标题行（如「会话规则」与它右侧的「新增会话规则」）
  在窄屏**保持同一水平线、让位的是标签文字而不是拆散按钮**；输入框始终
  完整可读、按钮不再盖住文字；**软键盘弹出时浮层自动收进剩余空间**（标题、按钮永不被顶出屏幕）；
  悬停操作与拖拽手势保持桌面原样（隐形热区加大、输入不再触发浏览器缩放、刘海/手势区安全间距
  自动避让）；卡片跨列移动自动把目标列滚入视野再播放落位动画——手机上看得见「飞过去」；即便系统
  开启「减少动画」，进行中的转圈与**呼吸**仍照常显示（放慢、变轻但不停止——静止的黄圈会被读成
  "卡死"，与真相相反）。
- **引擎状态看得见、也点得开**：同步模式下若排队的工作正等另一台设备执行，板头安静显示
  「引擎在另一端 · 排队中」；若服务端进程还是旧版（本插件的同步修复在 host 半区、需要重启才
  生效），板头显示「服务端未重启 · 点此了解」。**两者都是可点的按钮**（手机没有悬停，说明不能
  只做成鼠标提示），点开用一段话说清在等什么、该做什么（说明弹窗正文有正常的边距与呼吸）；
  **弹窗还会告诉你"当前连着的服务端进程是几点启动的"**——若你确实重启过却仍显示本条，一个时钟
  读数就能判定：那说明这个地址（例如隧道/端口）把你连到了**另一个没重启的实例**，重启那个即可；
  **重启服务端后，所有设备上的提示在一个心跳内自动消失**，不需要每台设备手动刷新页面；
  空闲时这条指示整个隐藏。
- **卡片颜色与整理**：悬停快捷色条与板顶整理栏同一套选色（调色板/自定义/移除颜色）；
  Ctrl/Cmd+点击多选 → 全选/清选/完成/删除（确认弹窗），选中卡片有清晰的动态光环。
- **复制为模板**：详情页一键以当前内容新建待规划卡（颜色与**任务级**自动化带上；执行
  记录、会话绑定与**会话规则**不复制——模板没有源任务的会话，「给某个会话发指令」的
  自动化不会跟着模板走）。未发送的输入自动记住草稿。

## 运行配置与预设

- **运行配置**：新建任务与任务编辑共用同一个配置编辑器（Agent / 工作区 / 模型 /
  思考程度 / 权限），两处行为完全一致。
- **自动补全**：新建任务时 标题 / 描述 / 执行 Prompt 都可以不填（空 Prompt 只让任务
  不能运行）。**任何一次真正执行**都会补全缺失项（缺则补、填则守）：标题取执行 Prompt
  的第一行、描述取整个执行 Prompt；已填写的字段永远保持原样（评论/需求完善/外源对话
  不算真执行，不会碰它们）。
- **配置预设**：编辑器顶部一行「配置预设」——选择即**瞬间切换**表单的运行配置；「管理…」
  打开预设管理器：
  - **自定义**：新增 / 编辑——预设表单直接提供与任务表单**同一套配置字段**
    （工作区/Agent/模型/思考程度/权限），所见即所得，不再只有名称；
  - **默认配置**：把任意预设（包括「部署默认」）设为默认——每次新建任务自动应用；
  - **回退规则**：从未设置默认、默认预设被删、存储异常，一律回退「部署默认」（跟随部署
    原生的默认配置，即旧行为）——永远不会有悬空状态。

## 安装

本插件为独立插件目录，经 profile bundle 挂载到 web profile：

```sh
# 一键挂载
node scripts/dsh-task-board.js mount

# 查看状态
node scripts/dsh-task-board.js status

# 卸载（重启后恢复原状；任务数据保留在 host 存储单元与浏览器）
node scripts/dsh-task-board.js unmount
```

也可用官方 profile 机制：`dsh plugin --profile web add link:<插件目录路径>`。

安装后**重启 `dsh web`**（页面刷新不够）；之后 client 半区的改动刷新页面即可生效。

## 数据存储位置

- **真相在 DSH host**：`~/.dsh/storages/dsh_task_board.json`（任务台账 + 巡航 + 定时预设 +
  运行配置预设 + 删除墓碑，单文件原子写、人可读、可直接备份；删除该文件 = 清空看板）。
- 浏览器 localStorage 各键为**离线镜像/本地状态**（断网首屏秒开、刷新不丢）：
  `dsh.taskBoard.v1`（台账镜像）、`dsh.taskBoard.cruise.v1`、`dsh.taskBoard.presets.v1`、
  `dsh.taskBoard.runPresets.v1`；草稿 `dsh.taskBoard.drafts.v1` 是**设备本地**未发送输入
  （刻意不跨设备同步）；首连时若本地数据与 host 分歧，本地副本备份到
  `dsh.taskBoard.preSync.v1`（host 真相优先）。
- host 若未挂载存储后端，看板自动退回纯 localStorage 模式（旧行为），功能不受影响。
- 迁移说明：首连时 host 为空 → 本设备数据整体上传；host 已有数据（如另一台先连）→
  本设备记录按「新者胜」并入，共享配置（巡航/预设）以 host 为准，本地分歧副本备份到
  `dsh.taskBoard.preSync.v1` 备查。

## 快速验证

1. 多端同步：电脑建一张卡 → 手机刷新/秒级自动出现；手机拖动/编辑 → 电脑实时跟随；
   两端同开跑一次定时任务 → 只执行一次；两端各拖一次**会话排序** → 顺序两端一致；
   手机**隐藏/恢复会话、隐藏托盘删除、关掉某条自动化规则** → 电脑与刷新后都保持
   （不再"刷新又活过来"）。
2. 手机布局：看板约两列同屏、**五个列标签一屏排满且各自可辨**（短名，导航条自身不用滑）；反复
   开合侧栏看板**不左右跳位**；板头行结构恒定——**第 1 行 返回·板名·自动巡航·新建任务**（都有文字），
   **第 2 行 状态组**（真有状态/提示才出现，「排队 0」不显示），**第 3 行 只有「筛选任务」这一条整幅白长条**，
   **第 4 行 整理·自动化**（右对齐）；点任务卡「评论」进入后**第一眼就是对话内容 + 下面的留言框**
   （发送框钉在面板底边），「上下文与运行配置」与「评论」是标题下**两个独立折叠、默认收起**；
   **把两个折叠同时展开到最长状态：对话与留言框依然完整可见、可点，谁也不截断谁**（折叠区在自己
   限高的一块里滚，「滑到最新」只驱动它所在的那一块）；折叠行箭头折叠朝右、展开朝下（全看板一致）；
   排队/插话的说明在发送框下面（折叠收起也看得见）；桌面头部一行 = 标题+徽标+上下文+刷新+查看会话+叉 同一水平线；手机头部第一行标题+徽标+叉严格同一水平线（叉在最右）、第二行 = 会话上下文（左）+ 刷新/查看会话（右）——上下文在刷新左边、统一水平面；**任务卡会话行：图形、工作区标签、状态徽章、时间行左边界完全对齐**，标题缩进在图形之后，未读点是压在图形右上角的小徽标（不占位、不会把标题挤成一个字）；
   巡航设置以整面板弹出可滚可选；
   「添加已有会话」标题在键盘弹出时仍可见；悬停色条/快速执行与桌面一样悬浮显示；会话排序就用
   拖拽；系统开「减少动画」时进行中转圈与**呼吸**仍然在动（放慢变轻，不停止）。
3. 原生对话上板：在任务绑定的原生会话里发一句话 → 卡片几秒内移入「进行中」并显示
   你那句话，跑完落「待审核」，两端一致；手机在前台时点「开始」**本地立即变化**。
4. 附件：评论/会话里选文件、拖放或粘贴（含 >1MB 照片手机相册直选、桌面 Ctrl+V 粘贴截图；图片浏览器内压缩、其他文件按原字节上传）→ 发送成功，评论区与对话里能看到缩略图、点开看原图；无法识别/超标的文件明确说原因（不静默丢弃）；**新建/编辑任务的「执行 Prompt」与需求完善回答框也能附**，执行时连同文字一起发出；发送按钮始终可见可点。
5. 引擎诚实：双端同开时，非引擎端若有留言排队，板头显示「引擎在另一端 · 排队中」；若显示
   「服务端未重启 · 点此了解」，点开看它报的**服务端启动时间**——时间就是你刚重启的那个 yet 提示仍在，
   或时间明显是旧的：说明该地址连的是另一个未重启的进程，重启那个即可（本条曾在非引擎端**永远**
   显示，因为被拒的租约应答漏发了协议版本；现已修好：重启 `dsh web` 后**所有设备一个心跳内自动消失**，
   手机无需手动刷新）。**手机上点这两条都能
   弹出说明**（不依赖鼠标悬停），说明弹窗正文边距正常、排版与其它弹窗一致。
6. 加载诚实：弱网/服务端刚重启时打开评论面板 → 配置区先显示安静的「读取中」而不是红色报错；
   读取失败会自行重试一次并留下「重试」按钮，切回前台也会再试；对话读取失败同样自动恢复。
7. 僵尸轮自愈：某次执行注入后会话始终没跑起来 → 三分钟内该轮自动结算为已取消并释放额度，
   之后该会话的原生对话照常驱动卡片；带未结算轮的进行中卡片不允许被拖走（会给出原因）。
8. 表单行让位与对齐：手机上打开自动化/Cron 编辑与「管理预设」→ 输入框始终完整可读、按钮换到下一行
   而不是把输入压成一个小方块；**「会话规则」与「新增会话规则」在手机上也在同一水平线**（与桌面一致），
   展开自动化后体内不再重复出现第二行「未启用」；桌面与手机的任务详情里，「添加会话 / 新建会话」
   与左侧那句说明**同一水平线**、并紧贴下方会话列表的上边界；详情底部「删除」与其他按钮同高、与「创建于」同一水平线。
9. 归档同步：在原生工作区归档一个已绑定会话 → 卡片上那一行两端即时消失；取消归档即时回来。
10. 新建任务：运行配置/预设/模型/Agent 目录正常可选（面板任何高度都完整可用）；填了
   「执行 Prompt」才能执行，留空时执行入口禁用、自动化摘要显示「执行 Prompt 为空」。
11. 运行配置预设：新建一个预设并「设为默认」→ 重新点「新建任务」，运行配置已自动应用。
12. 自动化总览：只出现已启动自动化的任务；展开任一卡片可切「完成后接续」并设上限。
13. 交互卡：让 agent 挂起提问 → 答案按钮行自动换行、不爆框、滚动条贴卡边，下方发送区不受影响。
14. 拖拽：拖卡片贴近列底部 → 列自动滚动，插入条跟到底部不消失；主界面/工作区新建
    会话 → 任何任务卡片都不会自动多出该会话。
15. 草稿：新建会话弹窗填一半标题/改配置后关掉再打开、会话规则写一半指令后退出再进 →
    内容都还在（评论、任务编辑、需求完善、新建任务本就如此）。
