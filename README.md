# dsh-task-board — DSH Web GUI 任务看板插件

在侧边栏「新会话」下方增加**任务看板**入口：多列看板管理任务，任务以 DSH 自身的会话机制
**真实执行**，状态实时回写卡片。不修改 DSH 源码，卸载即恢复原状；任务数据本地持久化。

## 核心能力

- **五列看板**：待规划 / 待办 / 进行中 / 待审核 / 已完成。卡片只显示状态摘要（标题、描述、
  来源、状态与自动化徽章、更新时间），执行窗口与评论时间线在详情页。
- **真实执行**：点「执行」即开跑；执行会话出现在原生会话列表，可点进去看完整对话。
  执行 Prompt 以 `/` 开头时按原生命令执行（如 `/plan ...` 真实进入计划模式）。
- **执行 Prompt 为空时什么都不跑**：手动点执行、快速执行、重新执行、定时/接续自动化、
  自动巡航、会话规则、评论排队与插话——只要 Prompt 是空的，全部拒绝（界面会提示原因）。
  需求完善流程不受影响（它正是用来产出 Prompt 的）。
- **评论即驱动**：每条会话行打开对应面板，左侧实时对话（Markdown 预览），右侧计量、
  运行配置、评论线程与发送区。留言默认**排队**（按顺序注入、可取消），或切**插话**
  立即送达；`/` 斜杠命令走原生命令注册表；可发图片（随留言即时送达）。
- **agent 挂起时评论区即答**：计划确认/提问卡实时出现，直接提交回复（走原生问答通道，
  普通留言不解决挂起问题）；同区的 to-do / goal / 子代理与原生 TodoPanel 同源显示，
  且**有未完成的才显示**（全部完成即收起）。
- **状态光效**：卡片与会话行按状态呼吸（进行中 / 等待回应 / 完善中；已结束未读也呼吸），
  打开详情或复盘即清除；已读已结束与空闲保持安静。
- **需求完善**：待规划任务让 AI 调研你的需求、逐条提问，产出可执行 Prompt（确认后才应用）。
- **自动化（一套系统，两处表面）**：任务详情与看板「自动化」总览是**同一个完整编辑器**
  （分「任务自动化」「会话规则」两个分区）。任务级 = 定时 cron / **完成后接续**
  （含次数上限、跳过本次、停止接续）；会话级 = 给某个会话定时发指令（排队/插话）。
  两半**互相独立**：关任务级计划表不影响会话规则，只有会话规则也不会误启动任务级自动化。
  就绪语义统一：任务不在「待办/进行中」时暂停并显示原因，移回即恢复。总览只显示
  **已启动**的自动化，每卡片一行实时摘要（含「接续 · 已运行 N/上限」）+ 启用开关 +
  展开编辑。
- **自动巡航（板级）**：看板头一键批量执行全部待办任务；全局并发上限；可设定时窗口——
  开始/结束分别可空（不填开始 = 立即开启，不填结束 = 一直保持；结束早于开始 = 跨次日，
  早于开始超过一天会提示日期错误）；窗口列表自动排序，每窗口一行文法（如
  「22:00 → 次日 02:00」「1月8日 09:00 起保持开启」）。
- **会话统一**：执行记录与链接会话合并为按会话去重的一个列表，同一会话同一条评论线程；
  列表可**上下拖拽排序**；展示可隐藏、隐藏托盘可恢复。**删除 = 从任务移除**（清记录），
  **显式拖回（会话或工作区）即可恢复显示**。任务已完成时留言自动把它移回「待办」并驱动。
- **拖拽**：卡片拖列移动、同列重排（精确插入条）、**拖到列边缘自动滚动**（一次拖到底/
  到顶）；侧边栏会话/工作区直接拖进看板建卡（拖进详情「会话」区 = 多源绑定，绝不刷新替代；
  拖入正在运行的会话立即同步状态）。
- **卡片颜色与整理**：悬停快捷色条与板顶整理栏同一套选色（调色板/自定义/移除颜色）；
  Ctrl/Cmd+点击多选 → 全选/清选/完成/删除（确认弹窗），选中卡片有清晰的动态光环。
- **复制为模板**：详情页一键以当前内容新建待规划卡（自动化规则、颜色全带上，执行记录
  不复制）。未发送的输入自动记住草稿。

## 运行配置与预设

- **运行配置**：新建任务与任务编辑共用同一个配置编辑器（Agent / 工作区 / 模型 /
  思考程度 / 权限），两处行为完全一致。
- **配置预设**：编辑器顶部一行「配置预设」——选择即**瞬间切换**表单的运行配置；「管理…」
  打开预设管理器：
  - **自定义**：新增 / 编辑（把当前表单配置存成预设）/ 删除任意预设；
  - **默认配置**：把任意预设（包括「部署默认」）设为默认——每次新建任务自动应用；
  - **回退规则**：从未设置默认、默认预设被删、存储异常，一律回退「部署默认」（跟随部署
    原生的默认配置，即旧行为）——永远不会有悬空状态。

## 安装

本插件为独立插件目录，经 profile bundle 挂载到 web profile：

```sh
# 一键挂载
node scripts/dsh-task-board.js mount

# 查看状态
node scripts/dsh-task-board.js status

# 卸载（重启后恢复原状；任务数据保留在浏览器）
node scripts/dsh-task-board.js unmount
```

也可用官方 profile 机制：`dsh plugin --profile web add link:<插件目录路径>`。

安装后**重启 `dsh web`**（页面刷新不够）；之后 client 半区的改动刷新页面即可生效。

## 构建

前置：Node ≥ 20，官方 NPM SDK 可访问（类型与运行时 API 全部来自 `@deepseek-ai/*`，
无需 DSH 源码 checkout）。

```sh
pnpm install
pnpm build      # 产出 lib/index.js + lib/client.js
pnpm typecheck
pnpm test       # vitest 单元与契约测试
pnpm verify     # 独立插件静态校验门禁（含禁 emoji、无 hex/rgb 审计）
```

## 数据存储位置

- 任务台账：浏览器 localStorage，键 `dsh.taskBoard.v1`（卸载后保留）。
- 自动巡航状态：键 `dsh.taskBoard.cruise.v1`；定时预设：`dsh.taskBoard.presets.v1`；
  运行配置预设：`dsh.taskBoard.runPresets.v1`；草稿：`dsh.taskBoard.drafts.v1`。
- 清除：浏览器控制台执行对应 `localStorage.removeItem(...)`。

## 快速验证

1. 新建任务：确认填了「执行 Prompt」；留空时看板上的执行入口为禁用态/无快速执行，
   自动化摘要显示「已暂停 · 执行 Prompt 为空」。
2. 运行配置预设：新建一个预设并「设为默认」→ 重新点「新建任务」，运行配置已自动应用。
3. 自动化总览：只出现已启动自动化的任务；展开任一卡片可切「完成后接续」并设上限。
4. 交互卡：让 agent 挂起提问 → 答案按钮行自动换行、不爆框，下方发送区不受影响。
5. 拖拽：拖卡片贴近列底部 → 列自动滚动，插入条跟到底部不消失。
