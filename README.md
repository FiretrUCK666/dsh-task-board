# dsh-task-board — DSH Web GUI 任务看板插件

在侧边栏「新会话」下方增加**任务看板**入口：多列看板管理任务，任务以 DSH 自身的会话机制
**真实执行**，状态实时回写卡片。不修改 DSH 源码，卸载即恢复原状；任务数据持久化在 DSH
host 端，**桌面与手机（任何设备、任何地址）打开同一部署看到的都是同一块板，改动实时同步**；
窄屏自动进入紧凑布局，触屏有完整的操作等价路径。

## 核心能力

- **多端实时同步（host 唯一真相）**：看板数据（任务、巡航、预设）由 DSH host 端持久化
  （`~/.dsh/storages/dsh_task_board.json`，人可读、可备份），浏览器只是乐观副本：
  电脑建卡 → 手机秒级可见，手机操作 → 电脑同步更新；同浏览器多标签也共享同一份真相。
  两端并发编辑按记录合并（新者胜、删除不被旧副本复活）；弱网/断线时看板照常可用
  （本地镜像先渲染），恢复后自动追平。首次升级自动迁移：各设备旧的 localStorage 数据
  按记录并入 host 初始数据（电脑的任务 + 手机上新建的任务都会出现），绝不丢。
- **引擎租约（多端绝不双跑）**：定时/巡航/接续/自动化发射等时间驱动行为同一时刻只由
  一个打开的 GUI 端执行（host 租约仲裁，秒级接管）；多端同开不会重复触发、不会重复
  消耗额度。手机上点「执行」等操作会中继到引擎端执行，反馈照常。

- **五列看板**：待规划 / 待办 / 进行中 / 待审核 / 已完成。卡片只显示状态摘要（标题、描述、
  来源、状态与自动化徽章、更新时间），执行窗口与评论时间线在详情页。
- **真实执行**：点「执行」即开跑；执行会话出现在原生会话列表，可点进去看完整对话。
  执行 Prompt 以 `/` 开头时按原生命令执行（如 `/plan ...` 真实进入计划模式）。
- **执行 Prompt 为空时执行全阻断**：手动点执行、快速执行、重新执行、定时/接续自动化、
  自动巡航、会话规则（把**任务执行 Prompt**作为内容的规则）——空 Prompt 一律拒绝
  （界面会提示原因；「完成后接续」不会假死：空 Prompt 时武装直接被拒并说明）。
  **评论与插话永不灰**：留言是人的话，只有会话不存在时才禁用。需求完善流程不受影响
  （它正是用来产出 Prompt 的）。
- **评论即驱动**：每条会话行打开对应面板，左侧实时对话（Markdown 预览），右侧计量、
  运行配置、评论线程与发送区。留言默认**排队**（按顺序注入、可取消），或切**插话**
  立即送达（官方 `steer` 模式——真插话：任务立即进入「进行中」、完成后落「待审核」并触发完成约定，与会话规则/外源轮共用同一运行态推导）；`/` 斜杠命令走原生命令注册表；**`@` 走官方引用机制**（与主界面输入框
  完全一致）：@ 文件/文件夹（`@"带空格路径"` 引号文法、目录下钻），@ 会话（插入
  官方 `@[会话](dsh-session:…)` 引用，发送后 host 自动把被引用会话的快照注入上下文
  ——所有输入框共用同一套；会话域官方候选不可用时（如目标会话由子代理路由托管，
   官方与主界面同样静默）会自动以板内会话目录列出（插入的仍是官方 `@[label](dsh-session:…)` 引用，host 照常解析快照上下文）；
   文件域失败时与主界面一致地静默（原因见浏览器控制台日志）；只有两域都成功且真无候选才显示「没有匹配的文件或会话」；
   选中后菜单即关、只有选目录才自动续开下一层）；可发图片（随留言即时送达）。
- **@ 引用能力边界（官方身份政策，如实说明）**：官方把「子代理路由会话」（会话起源为 subagent、或挂在活跃父代理下的会话）上的通用 RPC 一律拦截（`agent-busy`，官方语义：子代理会话请走子代理投递通道）——主界面官方 composer 在此类会话里 @ 同样不可用，且官方无版本修复（该政策自 rc.8 起即目前形态）。因此 @ 请以普通会话（`session-` 前缀）为目标，即可与官方完全一致地引用文件与会话；在子代理会话中，板内输入框以「板内会话目录 + 官方引用文本」提供 @ 会话（宿主照常解析），文件引用不可用（官方政策）。
- **agent 挂起时评论区即答**：计划确认/提问卡实时出现，直接提交回复（走原生问答通道，
  普通留言不解决挂起问题）；同区的 to-do / goal / 子代理与原生 TodoPanel 同源显示，
  且**有未完成的才显示**（全部完成即收起；进行中的 goal / 子代理才出现）。
- **状态光效**：卡片与会话行按状态呼吸（进行中 / 等待回应 / 完善中；已结束未读也呼吸），
  打开详情或复盘即清除；已读已结束与空闲保持安静。
- **需求完善**：待规划任务让 AI 调研你的需求、逐条提问，产出可执行 Prompt（确认后才应用）。
- **自动化（一套系统，两处表面）**：任务详情与看板「自动化」总览是**同一个完整编辑器**
  （分「任务自动化」「会话规则」两个分区，总览卡片 = 一行实时摘要 + 展开编辑，无重复
  开关）。任务级 = 定时 cron / **完成后接续**（**武装即开跑、完成后自动一直接续下一轮**，
  无限或至次数上限；含跳过本次、停止接续；手动移动卡片不会误杀它）；
  会话级 = 给某个会话发指令：内容二选一（自定义指令 / **任务执行 Prompt**——把任务的
  执行 Prompt 定时或每次完成时注入单一会话，改 Prompt 即时生效），触发方式二选一
  （**按时间表** / **每次完成**——完成后继续、一轮接一轮：永续循环，规则的指令轮
  成功结束才续下一轮；关闭/删除/会话消失/内容不可用才停）。**「每次完成」要先完成
  一次才会发第一条**：给会话留言/对话、跑一次任务都算完成；已启动但还没触发时，
  规则行显示「等待任务完成触发」（不是「排队中」——发送方式才是排队/插话）。
  **每条规则都有发送方式
  （排队 = 按序等轮次，插话 = 完成/到点先发）**：所有规则轮走**自动化车道**——按时
  到点绝不空等板级巡航，预算内一次一个、按序注入，很多条规则同时到点也绝不瞬时齐发，
  每条规则同时在途至多一轮。**每会话至多一条规则**：
  同一个会话的自动化是一份定义，改它用编辑，绝不叠多个触发器）。两半互相独立：关任务级
  计划表不影响会话规则。总览只显示**已启动**的自动化。
- **自动巡航（板级）**：看板头一键批量执行全部待办任务；全局并发上限；可设定时窗口。
  **总开关是主权**：窗口只在到点自动开/关，增删窗口绝不改变当前开关状态——手动开开关关
  永远匹配得上，拔光窗口也稳定。窗口一行一种显示（「22:00 → 次日 02:00」「1月8日 09:00
  起保持开启」「已开启 · 至 9月17日 06:51」；次日只用于结束是开始**紧邻的第二天**，
  间隔多天按真实日期显示）；状态行永远解释「为什么现在是开/关」；
  结束早于开始 = 一晚内跨次日（超过一天会提示具体差了多少天，请检查日期）。
- **会话统一**：执行记录与链接会话合并为按会话去重的一个列表，同一会话同一条评论线程；
  列表可**上下拖拽排序**；展示可隐藏、隐藏托盘可恢复。**删除 = 从任务移除**（清记录），
  **显式拖回（会话或工作区）即可恢复显示**。任务已完成时留言自动把它移回「待办」并驱动。
  会话区动作行可**「+ 新建会话」**：按运行配置直接创建一个全新原生会话并加入本任务
  （初始配置 = 任务自身运行配置，可改可套预设），无需回到工作区新建。**标题选填**——
  填写即以此命名并固定（官方 rename，永不被自动改名）；留空则交给宿主自动命名
  （首次对话后自动生成），与新会话在原生侧的表现完全一致。配置/标题某一步没生效时
  会话仍会保留并明确提示。会话行上可**重命名**（行内铅笔图标）：与原生会话列表、
  原生侧标题**同步生效**，且重命名后的标题不再被自动改名。宿主尚未命名的会话
  统一显示「未命名」。
- **拖拽**：卡片拖列移动、同列重排（精确插入条）、**拖到列边缘自动滚动**（一次拖到底/
  到顶）；侧边栏会话/工作区直接拖进看板建卡（拖进详情「会话」区 = 多源绑定，绝不刷新替代；
  拖入正在运行的会话立即同步状态）。
- **手机/窄屏适配（以看板盒宽度自适应，与侧栏/分屏/窗口大小无关）**：紧凑档五列变为
  **横向滑动列**（整列可读、吸附对齐）；弹窗/详情/复盘改为随屏面板，超高可滚、底部按钮
  永远可达；触屏上悬停操作常显、小按钮热区加大、输入不再触发浏览器缩放；拖拽语义全部
  有点击等价（详情「移到某列」、会话行上/下移、详情「添加会话」选择器）；刘海/手势区
  安全间距自动避让。
- **卡片颜色与整理**：悬停快捷色条与板顶整理栏同一套选色（调色板/自定义/移除颜色）；
  Ctrl/Cmd+点击多选 → 全选/清选/完成/删除（确认弹窗），选中卡片有清晰的动态光环。
- **复制为模板**：详情页一键以当前内容新建待规划卡（颜色与**任务级**自动化带上；执行
  记录、会话绑定与**会话规则**不复制——模板没有源任务的会话，「给某个会话发指令」的
  自动化不会跟着模板走）。未发送的输入自动记住草稿。

## 运行配置与预设

- **运行配置**：新建任务与任务编辑共用同一个配置编辑器（Agent / 工作区 / 模型 /
  思考程度 / 权限），两处行为完全一致。
- **自动补全**：新建任务时 标题 / 描述 / 执行 Prompt 都可以不填（空 Prompt 只让任务
  不能运行）。**任何一次真正执行**都会补全缺失项（缺则补、填则守）：标题取执行 Prompt
  的第一行、描述取整个执行 Prompt；已填写的字段永远保持原样（评论/需求完善/外源对话
  不算真执行，不会碰它们）。
- **配置预设**：编辑器顶部一行「配置预设」——选择即**瞬间切换**表单的运行配置；「管理…」
  打开预设管理器：
  - **自定义**：新增 / 编辑——预设表单直接提供与任务表单**同一套配置字段**
    （工作区/Agent/模型/思考程度/权限），所见即所得，不再只有名称；
  - **默认配置**：把任意预设（包括「部署默认」）设为默认——每次新建任务自动应用；
  - **回退规则**：从未设置默认、默认预设被删、存储异常，一律回退「部署默认」（跟随部署
    原生的默认配置，即旧行为）——永远不会有悬空状态。

## 安装

本插件为独立插件目录，经 profile bundle 挂载到 web profile：

```sh
# 一键挂载
node scripts/dsh-task-board.js mount

# 查看状态
node scripts/dsh-task-board.js status

# 卸载（重启后恢复原状；任务数据保留在 host 存储单元与浏览器）
node scripts/dsh-task-board.js unmount
```

也可用官方 profile 机制：`dsh plugin --profile web add link:<插件目录路径>`。

安装后**重启 `dsh web`**（页面刷新不够）；之后 client 半区的改动刷新页面即可生效。

## 构建

前置：Node ≥ 20，官方 NPM SDK 可访问（类型与运行时 API 全部来自 `@deepseek-ai/*`，
无需 DSH 源码 checkout）。

```sh
pnpm install

pnpm typecheck
pnpm test       # vitest 单元与契约测试
pnpm verify     # 独立插件静态校验门禁（含禁 emoji、无 hex/rgb 审计）
```

## 数据存储位置

- **真相在 DSH host**：`~/.dsh/storages/dsh_task_board.json`（任务台账 + 巡航 + 定时预设 +
  运行配置预设 + 删除墓碑，单文件原子写、人可读、可直接备份；删除该文件 = 清空看板）。
- 浏览器 localStorage 各键为**离线镜像/本地状态**（断网首屏秒开、刷新不丢）：
  `dsh.taskBoard.v1`（台账镜像）、`dsh.taskBoard.cruise.v1`、`dsh.taskBoard.presets.v1`、
  `dsh.taskBoard.runPresets.v1`；草稿 `dsh.taskBoard.drafts.v1` 是**设备本地**未发送输入
  （刻意不跨设备同步）；首连时若本地数据与 host 分歧，本地副本备份到
  `dsh.taskBoard.preSync.v1`（host 真相优先）。
- host 若未挂载存储后端，看板自动退回纯 localStorage 模式（旧行为），功能不受影响。
- 迁移说明：首连时 host 为空 → 本设备数据整体上传；host 已有数据（如另一台先连）→
  本设备记录按「新者胜」并入，共享配置（巡航/预设）以 host 为准，本地分歧副本备份到
  `dsh.taskBoard.preSync.v1` 备查。

## 快速验证

1. 多端同步：电脑建一张卡 → 手机刷新/秒级自动出现；手机拖动/编辑 → 电脑实时跟随；
   两端同开跑一次定时任务 → 只执行一次。
2. 手机布局：看板列横向滑动、卡片可读；详情/复盘底部按钮可达；会话行「上/下移」与
   「添加会话」在触屏可用。
3. 新建任务：确认填了「执行 Prompt」；留空时看板上的执行入口为禁用态/无快速执行，
   自动化摘要显示「已暂停 · 执行 Prompt 为空」。
4. 运行配置预设：新建一个预设并「设为默认」→ 重新点「新建任务」，运行配置已自动应用。
5. 自动化总览：只出现已启动自动化的任务；展开任一卡片可切「完成后接续」并设上限。
6. 交互卡：让 agent 挂起提问 → 答案按钮行自动换行、不爆框，下方发送区不受影响。
7. 拖拽：拖卡片贴近列底部 → 列自动滚动，插入条跟到底部不消失。
