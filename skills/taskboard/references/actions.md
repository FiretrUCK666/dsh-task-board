## task.comment

危险级 `guarded`；经 `engine` 写入；动词 `speak`。

| `session` | 条件：这张卡挂了不止一个会话时必须指明 | 目标会话 |  |  |
| `text` | **是** | 要发的话 |  |  |
| `command` | 否 | 这是一条斜杠命令而不是一句话 |  |  |

## task.create

建一张新卡。执行 Prompt 是它能跑起来的唯一原因，所以必填。运行配置与来源可以在这一步一起给——建完再改一次是两步，而两步之间那张卡的状态是半成品。

危险级 `reversible`；经 `document` 写入；动词 `create`。

| 参数 | 必填 | 说明 | 可选值 | 缺省含义 |
| --- | --- | --- | --- | --- |
| `prompt` | **是** | 执行 Prompt：这条卡跑起来时真正送出去的那段话 |  |  |
| `title` | 否 | 一行标题 |  | 留空时由执行 Prompt 补，不会覆盖已填的标题 |
| `description` | 否 | 详情正文 |  |  |
| `status` | 否 | 落哪一栏 | `backlog`；`todo`；`done` | 只能落在人手能拖过去的栏；「进行中」「待审核」归执行器 |
| `beforeId` | 否 | 插到这张卡前面 |  | 只在同一栏内排序时需要 |
| `bind` | 否 | 建卡时直接挂上的来源（可多项）：kind 是 session 时给 { kind, sessionId }，是 workspace 时给 { kind, workspaceId } |  |  |
| `color` | 否 | 卡片强调色 |  |  |
| `workspaceId` | 否 | 跑在哪台机器上（决定文件放哪、能访问什么；选错会跑到别的项目目录里） |  | 留空 = 落到最近用过的工作区（没有就取列表第一个；一个都没有时这张卡跑不起来）。**它决定文件落在哪**：只在这次要跑东西、而且用户没说在哪儿时，先问一句再填 |
| `provider` | 否 | 模型供应方 |  | 留空 = 用宿主默认供应方。**供应方与模型要一起给才生效**：只给其中一个等于都没给 |
| `model` | 否 | 模型（决定能力与成本） |  | 留空 = 用宿主默认模型。**要和 provider 一起给才生效**：只给模型不会改变这次运行用的模型 |
| `reasoningEffort` | 否 | 思考档位（决定质量与耗时） |  | 留空 = 用宿主默认档位。**依附于 provider + model**：那两个没给时这一项不生效 |
| `agentPreset` | 否 | 代理预设（决定这条会话由谁扮演） |  | 留空 = 用宿主默认代理（回执会说明这一项走的是宿主默认） |
| `permission` | 否 | 权限预设（决定它能做什么；选错可能改坏文件） |  | 留空 = 用宿主默认权限。**它决定能做什么危险操作**：涉及删除或覆盖文件时，先问一句再填 |
